## How to run dashboard

### Prerequisite 
* Make Sure to place dataset ```output3.csv``` in root directory
* If you are using original dataset ```SGJobData.csv```: 
    * you may also place in root directory
    * change line 8 in app.py from ```output3.csv``` to ```SGJobData.csv``` (or whatever file name of dataset you are using)

### Running Steamlit
* Once Prerequisite above is done, run in root directory: ```streamlit run app.py```
